# Claims Board Challenge

## Brief
When a customer reports a car accident, the claim goes through several stages before it is paid. Build something claims handlers can open in a browser to see every claim at a glance and move it to its next stage.

## Setup
* VS Code, Git and Aider should already be installed.
* Start Aider from this folder: aider --model sonnet --read SPEC.md --read CONVENTIONS.md
* Set your API key for this terminal only. Never commit it.

## How we work
* Write SPEC.md first, then plan with /ask, build in small steps, test, review.
* Commit often with clear messages. Push when something works. Pull before you push.

## Demo
